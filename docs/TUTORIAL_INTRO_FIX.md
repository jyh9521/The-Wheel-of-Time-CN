# 开场遗漏段落：Tes_01来源修正

> 历史开发与测试记录：下述测试数、待办、验收状态和产物名称对应记录时的构建，不代表正式版当前状态。v1.0 已完成完整通关测试且未发现补丁问题；正式文件为 `WoT-CN-v1.0.exe`。当前说明见 [项目主页](../README.md)、[安装说明](PORTABLE_INSTALLER.md)和[显示限制](KNOWN_ISSUES.md)。

测试记录（2026-10-03）：开场之后听到“the first time…”但无字幕；其他已测试教程文本无问题。反馈并非每个条件分支都触发的证明。

## 已确认根因

原版DialogA.Tes_01只有350字符；已固定hash的社区表有432字符。新增82字符为首次试炼说明，恰好对应测试反馈中的片段。两者是同一字幕key，不是应当新增Tes_81。

之前保守合并一律保留原非空文本，Tes_01被列冲突而保留，造成遗漏。此前“80/80 key有中文”没有证明音频每个段落都有字幕；此结论应据此收窄。

本地只读提取Tes_01的RIFF显示音频31.251秒；未自动转录、未启动游戏、未逐句听校。音频时长只做辅助证据，不能据此声称精准字幕同步。

## 最小修复

- profiles/subtitle-source.json仅批准Tes_01替换；同时验证原350字符与社区432字符的精确source SHA，合并后的完整文件SHA也重新绑定。
- 其余Tes_15/Tes_51两个非空冲突继续保留原文，17个社区遗漏键不删除；242空键/3新增键的行为不变。
- 语言无关工具增加approved_overrides和明确的译文组合规则，不盲目覆盖所有非空内容。错误来源hash、未批准ID、重复ID均失败。
- locale.config.subtitle_overrides单独指定字幕译文覆盖表，仅--subtitle-source启用时组合。原strings.json的116条与其他245条字幕行不修改，只替换构建时Tes_01这一行。
- 中文保留开场原译文，并追加“第一次试炼，面对的是过去。归途只会出现一次。坚定你的意志。”
- 源长度补偿从350改为432，避免遗漏段落按旧长度提前消失；继续使用同一key整段字幕，不修改游戏脚本、语音、地图或引擎。实际出现/消失时刻仍待复测。

## 修改范围与使用

与上一教程测试包逐条比较，仅WoTsubtitles.int的DialogA.Tes_01值改变；WOT.u、WoT.int、Angreal.int逐字节相同。字体仍607字符，没有新增Font或字节码变化。

该阶段更新本地build/runtime隔离副本，不启动游戏，不动原游戏。复测仍从System目录运行WoT.exe Tutorial，听到首次试炼说明时检查新增中文是否可见及是否提前消失。

完整版教程构建需要--subtitle-source COMMUNITY，纯原版默认构建保留原350字符来源与旧行，不声称补全该缺段。来源覆写的两组hash以及本地验证见构建报告；社区英文仍不入库。
