## 现在如何测试

本地隔离副本build/runtime已安装该阶段四资源，不覆盖原游戏。进入它的System目录启动WoT.exe，选择教程；只看1920×1080。不要把该路径与原安装混淆。该阶段工具未启动游戏。

也可解压本地预览ZIP，使用Python（安装器仅依赖标准库）向一份支持指纹的原版游戏副本应用：

```powershell
python -X utf8 install.py apply --bundle PATCH.json --target "GAME_COPY"
python -X utf8 install.py verify --bundle PATCH.json --target "GAME_COPY"
# 测试结束恢复原版四资源
python -X utf8 install.py restore --bundle PATCH.json --target "GAME_COPY"
```

包内Manage-Patch.ps1提供同样的apply/verify/restore入口，必须显式传-GameDir。安装器不改配置，User.ini的[WOT.WOTPlayer]需bSubtitles=True，分辨率设1080p。首次安装自动备份四资源到目标.localization-backup；保留备份。已改版本先使用其原补丁回滚；本包校验不匹配时会停止，不覆盖未知版本。

## 完整走教程时重点观察

- Tes_01～Tes_13：开场、拱门、洞穴移动、地震与跳跃；后续对白需要实际推进场景，不能只站在开场等待。
- Tes_14～Tes_27：坠落、疗伤草根、静止疗效、潜水/溺水、攀爬和返回拱门。
- Tes_28～Tes_62：第二次试炼、储藏室、箱子/钥匙/闸门、移位、火焰护盾、反射、照明和火球。
- Tes_63～Tes_80：第三次试炼、临时墙、长矛陷阱、陷坑、两仪师/护法站位与命令、闸门、撤离和结束。
- 错误放置、停滞、受伤、溺水等分支未触发时记为“未触发”，不要当作字幕遗漏。对照TUTORIAL_QA.json中的ID填写结果。
- 优先截图最长的Tes_29、Tes_63、Tes_64；检查折行、末尾是否丢字、顶部笔画、文字是否压住HUD。
- 听完整句，检查字幕是否提前消失、延后过长、被音效或另一句话覆盖；暂停、死亡重试与两个教程地图间切换也要观察。

反馈请包含：阶段/操作、字幕大意或key、截图、分辨率、语音是否仍在播放、是否发生死亡/重试。原版语音的措辞/语种与英文可能不同，翻译基于现有文本，不声称已逐句听校。

## 术语与译文状态

沿用伊莱娜、白塔、特法器、气流冲击；该批暂定两仪师、护法、暗黑之友、暗帝、妖境、法达拉、兽魔人、魔达奥、光球、移位、火焰护盾、反射、火球。现以根目录[GLOSSARY.md](../GLOSSARY.md)为唯一术语基准：已定词严格遵守，未收录游戏专名已统一列入其中的待确认清单，不再由locale glossary单独决定。UI物品名称尚有英文，暂不把显示为英文误报成字幕缺失。

Tes_15与Tes_51原英文标点损坏；该批按语义翻译，不修改英文source hash，不把社区改写版本静默覆盖原文。译文不手工补空格，构建的Len补偿沿用源长度，只是避免明显提前消失，不是精确时码。
