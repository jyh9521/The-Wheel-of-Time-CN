# 已知问题与范围

- 基础116条草稿（教程80条），带来源共128条已有译文，仍非完整汉化；原英文大量保留。元素/Rarity/Charges等Inventory字段还未翻译。
- **4K UI/字幕偏小：保留为已知问题，不再专项适配。推荐玩家用1920×1080游玩。**
  原英文也存在同样问题；项目不通过只放大中文字或修改引擎来修复4K。
- 原生Canvas固定像素字体，高分辨率下文本占屏比例下降；资源方案不等于高DPI UI重做。
- Reg08计分板中文、所有菜单Options/HUD、未知长句还没有全覆盖验收。
- 仅BMP；无代理对、RTL/复杂shaping；实际用字超atlas页面容量时构建失败而非静默截断。
- 原字幕817空；缺文恢复、社区完整版核对及许可未完成。
- 地图实例、硬编码正文、原生窗口、视频轨不在当前构建回填范围。
- 字幕长度补偿没有多音轨/同时发声/精确时间码保障。
- 新语言有工具接口与合成测试，但缺实际游戏语言包验收。
- Windows10/11分别、显卡组合、存档/切图/战斗长时间稳定性还需测试。
- 工具读写UTF-8工程数据，只有UTF-16LE BOM的游戏中文读取已验证。
- 首次研究使用Windows字体，只能作为本地PoC；正式Release需明确选择可再分发字体。
- 差分当前是开发者本地构建产物，没有自动签名/玩家成品安装器/正式Release。
