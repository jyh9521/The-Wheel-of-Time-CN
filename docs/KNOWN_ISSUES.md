## 高分辨率下文字偏小

原版游戏使用固定像素尺寸的字体；分辨率升高后，菜单、物品说明等界面文字占屏比例降低，阅读时可能显得偏小。这是原版游戏的显示特性，不是汉化补丁引入的问题。

推荐选择 **1024×768** 分辨率，以获得更清晰易读的界面文字；最高不建议超过 **1920×1080**。补丁不重做原版 UI 的高分辨率缩放。
