当前完整通关测试入口为 build/readability-game/LAUNCH_GAME.ps1，采用整体 1.5 倍 UE 位图文字，FMV 不变。3 倍因实机说明溢出、标题重叠及菜单裁切放弃，不继续适配。启动前校验已在 powershell.exe 验证，完整通关测试尚未完成。

普通资源构建覆盖 20 个文件；FMV 构建另包含版本门禁及可回滚播放器差分。此前 187 项自动测试、14 片原生抽帧和独立回滚通过。中文显示 PoC 已在游戏内确认；整部英文配音听校、剧情同步与通关稳定性仍需正式测试。尚未发布正式 Release。

## 分辨率与显示测试

推荐 1920×1080；后续开发 QA 仅检查 1080p。历史 1366×768、1440p 代表帧抽查保留为阶段证据，不保证后续构建覆盖。4K 下原版固定像素字体/UI 偏小，列为已知问题，不做专项适配。

早期支持状态曾为 116 条基础草稿，启用社区来源时 128 条已有译文、教程 80/80 已译；该阶段并非完整汉化。原版字幕表历史统计为 897 键、817 空键，不能等同于 817 句缺文。社区合并后为 900 键、325 非空，详见 [字幕覆盖报告](SUBTITLE_COVERAGE.md)。

已验证 Unicode 菜单、Inventory 标题/正文/斜体引文及教学首句字幕。字体保留原 0–255 映射，CharactersPerPage 从 256 改为 64，按实际译文生成不超过 256×256 的 P8 atlas，追加资源并重建目录表；这是 Unreal/WoT 适配层限制，不是通用文件格式。六个 Font 对象及字幕绘制 Y 常量（0→24px）的调整保留原版行高，阶段检查确认 8370 个其他原导出保持。固定 24px 不是响应式布局，字幕长度补偿也不是音频时间码同步。合成测试无需游戏；真实构建和集成需提供原版游戏与覆盖字体。不能以桌面截图尺寸代替游戏内部显示模式。

详见 [QA 记录](qa.md)、[字形修复](GLYPH_LAYOUT_FIX.md) 与 [已知问题](KNOWN_ISSUES.md)。
