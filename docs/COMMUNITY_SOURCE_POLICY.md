# 社区优先字幕合并

2026-10-03起，以我下载并固定SHA-256的社区补全版为字幕来源主版本。

- 取原版和社区版全部key的并集，同key值一律采用社区版，包括空值。
- 社区缺少的原版key保留。不再按Sound匹配结果丢弃社区条目；匹配信息只做审计。
- 全量逐条验证：883个社区key的文本完全一致，17个原版独有key完整保留，共900个key、325个非空文本。
- 非空原文冲突共3条：Tes_01补全段落，Tes_15和Tes_51纠正标点/句子分隔。后两条现有中文含义完整，译文保留，来源hash、长度和控制符元数据同步更新。
- 完整原版与社区文件均保持原位置和hash，不把游戏文件或社区英文完整资源提交进源码仓库。
- 通用工具通过conflict_policy选择策略；正式字幕profile设为prefer-reference，不需要逐条手工批准内容后才合并。approved_overrides保存冲突来源指纹并绑定对应译文，而不是限制社区合并范围。
- 构建仍需构建时指定--subtitle-source；不带此参数的原版来源构建不包含社区补全。

之前的保守策略和单条Tes_01修复记录作为历史保留；现行策略以本文为准。完整采用社区版并不证明它覆盖游戏每一段音频或视频；自动审计负责发现可识别的数据缺口，实机测试重点放在显示、时序和稳定性，不要求玩家承担逐句排查来源差异。
