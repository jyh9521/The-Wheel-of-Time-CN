# 单人通关测试包

> 历史开发与测试记录：下述测试数、待办、验收状态和产物名称对应记录时的构建，不代表正式版当前状态。v1.0 已完成完整通关测试且未发现补丁问题；正式文件为 `WoT-CN-v1.0.exe`。当前说明见 [项目主页](../README.md)、[安装说明](PORTABLE_INSTALLER.md)和[显示限制](KNOWN_ISSUES.md)。

此页保留早期差分安装器的操作与验证记录。当前本地通关测试提供[绿色安装 EXE](PORTABLE_INSTALLER.md)，不再要求运行以下 CMD；[直接覆盖实验](OVERLAY_TEST_PACKAGE.md)另外保留。

## 从新装游戏开始

1. 安装 GOG 版《时光之轮》，按 GOG 安装流程准备 QuickTime。先正常启动英文游戏一次，确认运行正常，然后退出。
2. 将测试 ZIP **解压到游戏根目录**（该目录下应已有 `System`、`Maps`、`Movies`）。不要解压进 `System`，不要覆盖旧的开发测试副本。
3. 双击根目录 `Install-Localization.cmd`。出现 `APPLY PASS` 后，双击 `Verify-Localization.cmd`，确认 `VERIFY PASS`。
4. 双击 `Launch-Game.cmd`。入口调用 `System\WoT.exe`，不指定地图、不跳转教程、不载入测试存档；按正常片头、主菜单流程开始新游戏。
5. 硬件设置选择 1920×1080。此次不自动改分辨率、按键绑定或存档。字幕开关在安装时启用。

## 测试内容

菜单、按键提示、门锁与拾取提示、教程对白、剧情字幕、特法器说明、存取档及切图提示、过场电影中文字幕。菜单与物品字体保持原尺寸，顶部字幕采用专用 18px 字体；FMV 使用随包安装的思源黑体改名子集，不依赖系统中文字体。

重点记录章节/地图、触发操作、出现的原文或译文、截图，以及字幕缺失、时序、遮挡或崩溃。多人模式和记分板不作为此次通关测试目标。电影 Mission_10 经画面检查无对白，不添加字幕。

## 安装与恢复

安装脚本仅使用 Windows PowerShell 5.1 与 .NET，不需要 Python。原版文件逐个进行 SHA-256 和大小检查，未知或已修改版本在写入前退出。包内为差分、原创译文、脚本及字体子集，不含完整原版游戏程序或视频。

备份保存在游戏根目录 `backup`。卸载前退出游戏，运行 `Uninstall-Localization.cmd`，恢复原版资源；当前设置、存档槽位名称与存档文件保留。安装和恢复前均另存当前设置及存档快照。安装包文件与备份本身保留以便复查。

这是本地测试包，不代表已完成全流程通关验收。UE 位图字体当前仍为本地测试构建；公开发布前须完成对应字体与派生资源的许可核对。思源黑体子集许可证随包保留。本包不作为公开 Release 上传。

## 重建测试包

先按 BUILDING.md 重建并验证资源及 FMV/字体运行副本，再执行：

```powershell
python tools/build/package_player_test.py --game-dir "原版游戏目录" --resource-build "资源构建目录" --runtime-dir "已验证完整运行副本" --locale zh-CN --out "dist/wot-zh-CN-player-test.zip"
```

资源差分应用结果必须与运行副本逐字节一致，否则打包失败。ZIP 写出后逐成员重新读取核对，并输出 SHA-256 文件。
