## 已验证

2026-10-05，14 寸笔记本在 1920×1080 下的字幕过小；此前 27 寸显示器上的可接受结果不代表小屏幕可读性通过。

原版 WOT.u 内 BaseHUD.ScriptText 与 DrawMessages 表明，该消息绘制函数先调用 C.SetFont(Font'WOT.F_WOTReg14')，随后绘制字幕。字幕分支本身没有专用字体选择。当前汉化副本 F_WOTReg14 的主要中文字形矩形为 16×14，行高保持原版 14 像素。Legend.u 内 LegendCanvas.SetFont 仅在 SizeX<512 且未强制时选择 _S 字体；1080p 不自动放大。

同一 DrawMessages 还绘制手部、左右、中心及通用消息；直接扩大共享字体会影响其他 HUD 文本。菜单和物品说明也可能引用该字体，不能把全局字体改大当作字幕专项修复。

## 实施路线

1. 以 24 像素为第一候选，28、32 像素用于对照；候选尚未成为实机验证结果。
2. 游戏内字幕使用专用字号配置与字库；仅在字幕分支选用，完成后恢复原字体。优先资源/脚本层方案，保持现有分段字幕与声音触发。
3. 文本测量与绘制使用同一专用字体；联合检查行距、顶部边距、左右安全区、长句换行与标点避头。不能只放大字形纹理而保留旧 metrics。
4. 不依靠强制截断或改写译文适配宽度，不随意改动字幕时序。
5. FMV 属于 QuickTime 文本轨，字号字段、字幕轨高度及双行边界独立处理，不能复用 UE 字库缩放作为 FMV 修复。
6. 仅在独立候选副本验证；当前通关目录、配置与存档保持。实机检查后再确定默认字号。

## 当前产物与边界

已提供只读度量和 1920×1080 字号对照工具；预览使用本地字体，不是游戏截图，不代表真实 HUD 或 QuickTime 布局已验收。当前未改变游戏字号，也未启动游戏。

```powershell
python -m tools.validate.subtitle_readability --game-dir "GAME_COPY" --font "FONT.ttf" --out build/subtitle-readability
```

输出 AUDIT.json 和 SIZE_PREVIEW.png；输出目录必须不存在，原资源不修改。正式接入前需确认专用字体选择、测量、绘制和字体恢复，并检查存档/切图后仍生效。

## 1.5 倍整体文字候选（2026-10-05）

范围按整体可读性调整：六套已汉化 UE 位图字体的中西文、数字及其字宽/行高统一按 1.5 倍重采样。14→21、30→45、8→12 像素，低分辨率备用字体 7→11、15→23；整数尺寸四舍五入。共享这些字体的菜单、物品/特法器说明、按键与 HUD 提示、对白字幕随之放大。符号专用 Font 不改，Windows 原生高级设置窗口字号不在此次 UE 字体实验内。FMV 全部保持字节一致。

256 像素单 mip atlas 限制保留，CPP 从 64 调整为 16，以容纳较大字形；201 张新 atlas 和 Font 映射追加，原材质/共享纹理不覆盖。8443 个其他导出及原脚本逐字节保持。此次采用最近邻放大已有字形，优先验证大小；不是新字号矢量重栅格化，边缘可能出现像素感。

**布局尚待实机验收**：字宽与行高同步放大，但固定文本框、列距、图片按钮、特殊脚本坐标没有统一扩大。不能据资源校验宣称无重叠或裁切。先检查菜单、设置左右列、特法器说明的长段正文和引文、教程字幕与中心提示；出现问题后按实际页面单独调整。仅 1080p。

现有候选入口为 build/readability-game/LAUNCH_GAME.ps1，无显式地图参数，具有空的独立 Save；当前通关副本及存档不变。该候选不是最终版本。

可从现有完整本地字体副本重复构建到新的目录：

```powershell
python -m tools.build.build_readability_poc build --source-game build/local-font-game --scale 1.5 --out build/readability-game
python -m tools.build.build_readability_poc verify --out build/readability-game
```

上游普通汉化与 FMV/本地字体副本重建见 BUILDING.md 和 FMV_LOCAL_FONT.md；输入必须经过原完整副本校验。工具不修改原目录，不复制已有存档，不自动启动游戏。已安装候选的事务记录位于 build/readability-150；回滚仅输出基线已汉化 WOT.u 到另一份文件，不撤销当前候选。

## 3 倍整体文字候选

1.5 倍候选的教程字幕已实际显示，反馈仍偏小。按未放大的基线制作 3 倍候选，不叠加倍率：正文 14→42、标题 30→90、小字 8→24 像素；其余两套备用字体与斜体同比例放大。仍采用最近邻放大，不将显示大小等同于重栅格化质量。

CPP 按每套字体的最大字形尺寸选择 16/8/4/2/1 中可容纳的值，保留 256×256 单 mip 限制。不同字号使用不同 CPP，校验必须读取各自 Font 的 CPP，不能套用最后一套字体的值。第一次候选的此项检查失败，修正检查后在新目录重新构建；未覆盖已有副本。

完整候选入口：build/readability-game-3x/LAUNCH_GAME.ps1。3 倍资源、映射与回滚为静态验证；固定文本框、列距与图片按钮尚未逐页扩大，可能溢出或重叠，需在 1080p 检查。全部 FMV 保持不变，原通关和 1.5 倍副本保留。此次不自动启动游戏。

```powershell
python -m tools.build.build_readability_poc build --source-game build/local-font-game --scale 3 --out build/readability-game-3x
python -m tools.build.build_readability_poc verify --out build/readability-game-3x
```
