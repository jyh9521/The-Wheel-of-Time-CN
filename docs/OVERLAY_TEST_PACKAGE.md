# 直接覆盖版通关测试包

> 历史开发与测试记录：下述测试数、待办、验收状态和产物名称对应记录时的构建，不代表正式版当前状态。v1.0 已完成完整通关测试且未发现补丁问题；正式文件为 `WoT-CN-v1.0.exe`。当前说明见 [项目主页](../README.md)、[安装说明](PORTABLE_INSTALLER.md)和[显示限制](KNOWN_ISSUES.md)。

此页保留大体积直接覆盖实验。当前另提供[小体积绿色安装 EXE](PORTABLE_INSTALLER.md)，选目录、校验后自动合并差分，不需要手动运行 CMD。

1. 安装匹配项目指纹的 GOG 英文版游戏。GOG 安装所需的 QuickTime 保持可用。
2. 游戏退出后，将 ZIP 内所有内容解压并覆盖到游戏根目录，与 System、Maps、Movies 同级。不要额外套一层目录。
3. 直接使用 GOG 原游戏快捷方式，或运行 System\WoT.exe。无需 CMD、PowerShell、安装脚本或 Python，不指定教程、地图或测试存档。

本包面向新安装测试，包含从原版 Default.ini/DefUser.ini 重建的干净配置：字幕开启，建议分辨率 1920×1080，默认 Direct3D。覆盖会重置配置和按键设置；存档不包含在包内，也不删除。首次启动配置保留 FirstRun=0，可出现原生首次配置向导。向导选择可能调整显示配置，进入游戏后确认 1920×1080。

## 启动配置汉化

GOG 的正常启动与 Video Setup 共用 System\WoT.exe，Video Setup 参数为 -changevideo，不是另一个独立游戏启动器。首次配置、视频设备选择、细节选择、安全模式与恢复说明位于 Startup.int；通用向导位于 Window.dll/Window.int。本包包含这些中文资源，并补齐向导模板中的“下一步、返回、完成、取消”按钮回退文本。不修改 WoT.exe，不改变控件 ID、字体尺寸或按钮功能。

独立的 dxcfg.exe（DirectX wrapper 设置）和 nglide_config.exe（nGlide 设置）属于第三方显卡工具，不是上述游戏启动向导，此包未改动这两个程序。

## 包内内容与测试

当前中文文本、地图显示字段、按钮图像、原尺寸菜单与特法器说明、顶部专用 18px 字幕、14 段中文字幕电影，以及 FMV 配套思源黑体改名子集。Mission_10 无对白，不添加字幕。完整通关、字幕同步与长文本显示仍需实际测试，不宣称已完成通关验收。

这是本地覆盖测试产物，包含重建后的完整资源和电影，仅用于此次测试，不提交源码仓库或上传公开 Release。公开发布仍采用差分，并完成字体及派生资源许可核对。汉化文件清单记录包内大小、SHA-256 和对应原文件 SHA-256。

恢复方法：覆盖前保留原版对应目录与配置副本；恢复原文件后移除本包新增的 SubtitleRuntime.u、SubtitleRuntime.int、Fonts\WotFmv.ttf 和 Fonts\OFL.txt。存档保持原样。重新安装到另一个目录也可获得独立英文基线。
