## 实现与可逆性

`src/patch/map_prompts.py` 只重建白名单 FString 属性，不更改地图几何、碰撞、actor 类型、事件连接、状态帧、语音或脚本。修改后的 actor 导出追加到文件末尾，再追加 export table，头部只更新 ExportOffset（偏移 24）。其他导出保持原始记录与内容；对象数、名称表、导入表及 GUID 保持。

UTF-16LE FString 使用负 compact index，长度包含末尾 NUL，以 UTF-16 code unit 计数。字符串 property 使用显式 32 位长度标签，保留 array slot。回滚保存原始头部并截断追加区，最终完整文件 SHA-256 必须匹配。

16 个地图进入原版指纹 profile；安装器只接受匹配 profile、原始大小与 SHA-256 的 Maps/*.wot。默认构建生成差分，不分发完整地图。
