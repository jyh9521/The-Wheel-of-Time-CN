**尚未达到可证实的玩法与剧情文本 100% 中文覆盖。** 译文表已完成不代表显示路径已穷尽；构建成功也不代表游戏实测通过。本次检查实际测试副本，并补齐已确认的遗漏。

- 264 个实际文件全部读取并计算 SHA-256；第二次读回未发现输入变化。
- System 123、Maps 45、Textures 36、Sounds 27、Movies 17、Music 10、Fonts 3；另有启动脚本、安装清单和一个存档。
- 30 个 `.int`、UE 资源导出表、地图 actor 字符串、脚本源码/编译文字候选和 39 个 PE 文件的 ASCII/UTF-16 字符串均纳入扫描。
- 包内扫描提取 1,048 条非空类默认字符串；其中 140 条带 localized 标记的英文候选未找到精确 `.int` 覆盖项。此数不是已确认的遗漏数量：还需检查继承、数组索引、是否实际显示和代码覆盖。
- 136 条源码/编译文字关联候选需区分显示文案、调试输出、命令和英文查找键。
- 翻译表、社区合并层、已批准字幕覆写及原生窗口文案的实际文件读回：不匹配 0 项。
- 14 个有字幕的 FMV 中，628 条非空选定文本轨样本与中文稿一致；未发现英文正文。此前本轮口头汇总的 728 属于加总错误，以逐片清单的 628 为准。
- `Mission_10` 已确认无对白；两个品牌视频不生成剧情字幕。FMV 原有其他语言轨不作为当前选定中文字幕缺失项。

逐文件清单、大小、指纹和检查方法见 [FULL_TEXT_INVENTORY.json](FULL_TEXT_INVENTORY.json)。该清单证明读取范围，不证明每个执行分支均已实测。

转义扫描修正：已知 `\n` 与其后英文正文分开识别，避免将 `\nHowever` 整体误认为控制代码。已知转义与未知控制代码均有测试；占位符和实际 `\n` 数量保持不变。

## 合理保留项

- 类名、资源路径、命令、绑定键、布尔存储值、协议、URL 和占位符保持可解析。
- 字幕运行时 `MessageSource[]` 是英文精确匹配键；`MessageTarget[]` 才是显示译文。
- Enter、Esc、Shift 等键帽名称、API 和驱动品牌可保留，不等于整句未翻译。
- 原贡献者姓名、品牌标志及原版权主体不改写为汉化作者。
- 图片只处理已确定的八张按钮；书页、挂毯等图片文字保持既定范围。
- 原版安装器、编辑器和命令行帮助单独列出，不混入正常玩法与剧情完成率，也不据此宣称全文件无英文。

## 复现与发布门槛

```powershell
python -X utf8 -m tools.validate.full_text_audit --game-dir <测试游戏目录> --locale zh-CN --out build/text-audit
python -X utf8 -m tools.validate.full_text_audit --game-dir <测试游戏目录> --locale zh-CN --out build/text-audit --require-complete
python -X utf8 build.py test
```

首条命令检查读回、结构与文件覆盖，不启动游戏。结构/指纹/译文读回或 FMV 对照失败返回 1。第二条当前返回 2，并明确显示 `COVERAGE INCOMPLETE`；不会将已完成译文数量误作 100% 验收。

原始字符串候选、完整原脚本及二进制差分只保存于忽略的 `build/`，不提交完整游戏资源。本批回滚在独立副本中执行并逐字节对照基线；实际测试副本保留更新版。
